Program Studi

Pilihan program unggulan untuk masa depan pertanian yang inovatif

Fakultas Pertanian UM Berau menyiapkan calon lulusan yang siap menghadapi tantangan sektor pertanian, pangan, dan bisnis agro di era modern.

AG

Agroteknologi

Mempelajari teknologi budidaya tanaman, pengelolaan lahan, perlindungan tanaman, dan inovasi produksi pertanian yang ramah lingkungan.

  • Budidaya tanaman modern
  • Pertanian presisi dan berkelanjutan
  • Manajemen produksi dan kualitas hasil
AB

Agribisnis

Fokus pada pengelolaan usaha pertanian, rantai pasok, kewirausahaan, pemasaran produk agro, dan strategi pengembangan bisnis berdaya saing.

  • Manajemen usaha tani
  • Ekonomi pertanian dan pemasaran
  • Kewirausahaan sektor agro
IN

Kelas Adaptif

Struktur kurikulum dapat menyesuaikan kebutuhan kampus dan perkembangan lokal, termasuk praktik lapangan, riset terapan, dan penguatan soft skills.

  • Pembelajaran kolaboratif
  • Praktikum dan studi lapangan
  • Penguatan kompetensi profesional

Syarat Pendaftaran

Siapkan berkas utama sebelum mengisi formulir pendaftaran

Pastikan data diri dan dokumen yang diunggah jelas, valid, dan masih dapat dibaca agar proses verifikasi oleh panitia berjalan lebih cepat.

Dokumen Wajib

  • Pasfoto 3x4 terbaru
  • KTP atau Kartu Pelajar
  • SKL atau Ijazah
  • Kartu Keluarga

Ketentuan Berkas

  • Format file JPG, JPEG, PNG, atau PDF
  • Ukuran file disarankan maksimal 2 MB per dokumen
  • Nama file dibuat jelas dan mudah dikenali
  • Pastikan hasil scan atau foto tidak buram

Alur Pendaftaran

Langkah mudah untuk bergabung di Fakultas Pertanian UM Berau

1

Isi Data Diri

Lengkapi identitas pribadi, kontak aktif, dan informasi pendidikan terakhir.

2

Pilih Prodi

Tentukan program studi yang sesuai dengan minat dan rencana karier Anda.

3

Unggah Berkas

Lampirkan pasfoto, identitas, serta SKL atau ijazah untuk verifikasi panitia.

4

Kirim Pendaftaran

Sistem akan mengirim data ke Google Apps Script untuk dicatat ke Drive dan Sheets.

Form Pendaftaran

Kirim data pendaftaran secara online dalam satu formulir

Setelah menekan tombol kirim, sistem akan memproses data teks dan file upload menjadi payload yang siap diterima oleh Google Apps Script Web App.

Catatan

Gunakan email aktif dan nomor WhatsApp yang dapat dihubungi panitia PMB.

Dukungan Integrasi

File akan dibaca sebagai Base64, lalu dikirim melalui `fetch()` ke Apps Script.

Keamanan Data

Sebaiknya aktifkan validasi dan pengaturan akses pada Web App Google Apps Script Anda.

Upload Berkas

File akan dibaca sebagai Base64 untuk siap dikirim ke Web App Google Apps Script.

Ganti nilai `SCRIPT_URL` di file `script.js` dengan URL Web App Google Apps Script Anda sebelum digunakan secara produksi.
Silakan lengkapi data dan unggah berkas yang diminta.
